# 2. Van JavaScript naar TypeScript

| Veld | Waarde |
|---|---|
| Wat je leert | Wat TypeScript is, hoe je het in een project zet, hoe je een typefout leest, en het verschil tussen nakijken en uitvoeren |
| Je gebruikt uit hoofdstuk 1 | Het pakket `domein`, npm-scripts, de debugger en het voorraadscript |
| Wat je oplevert | `domein` in TypeScript, met een `tsconfig.json`, een script `check` en `prijs.ts`: rekenen met prijzen in cent |
| Waar je het later gebruikt | In elk hoofdstuk van dit jaar. React, Express, NestJS en Next.js schrijf je allemaal in TypeScript |

In hoofdstuk 1 telde een script `3 + 12 + 40` op tot `031240`. JavaScript vond dat
prima. Dit hoofdstuk zet een hulp naast je die zulke fouten vindt **voor** je het
programma uitvoert.
