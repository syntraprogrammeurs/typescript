# 7.12 Voor wie klaar is

1. Schrijf `isCategorie` en `isPagina`. Voor een pagina moet je ook elk blok nakijken: hoe
   hergebruik je het idee van de `switch` uit hoofdstuk 6?
2. Laat `laadProducten` niet bij de eerste fout stoppen, maar alle fouten van alle
   producten verzamelen en in één melding tonen. Wanneer is dat beter?
3. Zoek op wat de *reviver*, de tweede parameter van `JSON.parse`, doet.
4. Lees de korte uitleg *Type Assertions* in het TypeScript-handboek
   (`https://www.typescriptlang.org/docs/handbook/2/everyday-types.html`). Welk voorbeeld
   met `document.getElementById` geven ze? Waarom is `as` daar aanvaardbaar?
