# 1.2 Waaruit je werkplek bestaat

| Onderdeel | Wat het doet | Wat wij gebruiken |
|---|---|---|
| De runtime | Voert JavaScript en TypeScript uit buiten de browser | Node.js 24 LTS |
| De package manager | Installeert pakketten en voert scripts uit | npm, komt mee met Node |
| De taal | JavaScript met types | TypeScript 7, vanaf hoofdstuk 2 |
| De editor | Waarin je typt, met hulp bij elke regel | Visual Studio Code |
| De terminal | Waarin je commando's geeft | PowerShell, in VS Code |
| Het versiebeheer | Bewaart de geschiedenis van je project | Git |
| De opslag online | Bewaart je repository, ook als je laptop crasht | GitHub |

> **BEGRIP — Runtime**
>
> Een **runtime** is het programma dat je code uitvoert. In de browser is dat de
> JavaScript-motor van Chrome, Firefox of Safari. Buiten de browser is dat **Node.js**.
>
> *Waarom je het nodig hebt:* de browser kan geen bestanden lezen, geen server starten
> en geen databank aanspreken. Node kan dat wel. Alles wat je dit jaar buiten de browser
> bouwt, draait in Node.

Je kent HTML, Tailwind en JavaScript. Wat er in de browser gebeurt, is dus niet nieuw.
Nieuw is dat dezelfde taal nu ook op je eigen computer en later op een server draait.
