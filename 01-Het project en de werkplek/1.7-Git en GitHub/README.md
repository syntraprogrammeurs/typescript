# 1.7 Git en GitHub

Je kent Git al. Controleer of het geïnstalleerd is en goed staat ingesteld:

```powershell
git --version
git config --global --list
```

> **CONTROLE**
>
> Je ziet je naam, je e-mailadres en `init.defaultbranch=main`. Ontbreekt er iets, stel
> het dan nu in. Het e-mailadres moet hetzelfde zijn als dat van je GitHub-account,
> anders koppelt GitHub je commits niet aan jou.
>
> ```powershell
> git config --global user.name "Jouw Naam"
> git config --global user.email "jouw.adres@voorbeeld.be"
> git config --global init.defaultBranch main
> ```

Meld je aan op `https://github.com`. Je hebt er dit jaar één repository nodig. Die maak
je in paragraaf 1.12.
