# 1. Het project en de werkplek

| Veld | Waarde |
|---|---|
| Wat je leert | Wat je dit jaar bouwt, en hoe je je werkplek opzet: Node.js, npm, VS Code, Git en GitHub |
| Wat je nodig hebt | Een laptop met beheerdersrechten, internet en je GitHub-account |
| Wat je oplevert | De repository `groenhuis` op GitHub, met een eerste pakket `domein` waarin Node een script uitvoert |
| Waar je het later gebruikt | Overal. Elk hoofdstuk van dit jaar begint in de map die je hier maakt |

Dit hoofdstuk schrijft nog bijna geen code. Het zet de plek klaar waar je het hele
jaar in werkt, en het toont wat je aan het einde van dat jaar gebouwd hebt. Wie weet
waar hij naartoe gaat, begrijpt beter waarom een stap nodig is.

> **WAAROM**
>
> Waarom één project voor het hele jaar, en niet elke week een nieuw oefenprogramma?
> Omdat echte software zo groeit. Je schrijft iets, je bouwt erop verder, en drie
> maanden later moet je het aanpassen zonder dat de rest stukgaat. Dat leer je alleen
> als je drie maanden later nog met dezelfde code werkt. Elke nieuwe technologie die je
> dit jaar leert, **vervangt** bovendien iets wat je zelf gebouwd hebt. Zo zie je wat ze
> voor je doet.
