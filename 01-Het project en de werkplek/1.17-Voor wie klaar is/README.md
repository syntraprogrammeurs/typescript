# 1.17 Voor wie klaar is

1. Typ `node` zonder bestandsnaam. Je komt in de **REPL**, een plaats waar je regel per
   regel JavaScript uitvoert. Probeer `0.1 + 0.2` en `"3" * "4"`. Je verlaat de REPL met
   `.exit`.
2. Zoek op wat `npx` doet, en hoe het verschilt van `npm`. Je gebruikt het in het
   volgende hoofdstuk.
3. Zet in `package.json` bij `engines` tijdelijk `">=30"` en voer `npm start` uit.
   Waarschuwt npm? Zoek op wat de instelling `engine-strict` doet. Zet de waarde terug.
4. Kijk op `https://nodejs.org/en/about/previous-releases` tot wanneer Node 24
   ondersteund wordt.
