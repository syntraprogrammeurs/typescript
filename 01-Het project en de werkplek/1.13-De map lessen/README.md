# 1.13 De map `lessen`

Bij deze cursus hoort een map `lessen`. Daarin staat per hoofdstuk een map, en daarin
een map per paragraaf, met de nummering van deze bundel. Elke paragraaf heeft er een
`README.md` met de tekst, en de proefcode uit die tekst staat er als bestanden in
`voorbeelden`. Waar code van het project verandert, en bij elke klassikale oefening, staat
er ook een **startpunt** en een **oplossing**.

```text
lessen/
├── 01-Het project en de werkplek/
│   ├── README.md
│   ├── 1.1-Wat we het hele jaar bouwen/
│   │   └── README.md
│   ├── ...
│   ├── 1.5-JavaScript buiten de browser/
│   │   ├── README.md
│   │   └── voorbeelden/
│   ├── ...
│   ├── 1.8-De projectmap/
│   │   ├── README.md
│   │   ├── startpunt/
│   │   └── oplossing/
│   ├── 1.9-Het eerste pakket/
│   └── ...
├── 02-Van JavaScript naar TypeScript/
└── ...
```

| Bestand of map | Wat erin staat |
|---|---|
| `README.md` | De tekst van de paragraaf, met de echte uitvoer |
| `voorbeelden/` | De proefcode uit de tekst, met bovenaan in commentaar waar het om gaat, de opbouw van de code en hoe je ze uitvoert, en onderaan wat ze toont |
| `startpunt/groenhuis` | Het project zoals het is **voor** je aan de paragraaf begint |
| `oplossing/groenhuis` | Het project zoals het is **na** de paragraaf. De bestanden die in de paragraaf veranderen, hebben bovenaan in commentaar de uitleg en de opbouw; bij een klassikale oefening de opgave, ook in het startpunt |

De oplossing van een paragraaf is precies het startpunt van de volgende. Mis je een les,
of loopt er iets vast dat je niet meer terugvindt: kopieer het startpunt van de
paragraaf waar de klas staat naar `C:\cursus`, en je bent weer mee.

> **LET OP**
>
> Gebruik de oplossing om te **vergelijken**, niet om over te nemen. Wie de oplossing
> kopieert zonder het zelf geprobeerd te hebben, heeft over een maand een project dat
> werkt en een hoofd dat niet weet waarom.
