# Lessen — startpunten en oplossingen

Deze map wordt gebouwd door `deel-1/bouw.py`. Wijzig hier niets met de hand: de inhoud komt uit `deel-1/stappen/`.

Per hoofdstuk staat er een map per paragraaf of oefening waarin code verandert. Daarin:

| Map | Wat erin staat |
|---|---|
| `startpunt/` | het project zoals het is **voor** je aan die paragraaf begint |
| `oplossing/` | het project zoals het is **na** die paragraaf |

De oplossing van de ene paragraaf is het startpunt van de volgende. Mis je een les, kopieer dan het startpunt van
de paragraaf waar de klas staat naar je eigen werkmap, open een terminal in de map `domein` en typ `npm install`.
