# 3. Functies typeren

| Veld | Waarde |
|---|---|
| Wat je leert | Functies precies beschrijven: wat erin gaat, wat eruit komt, wat weg mag, en functies die je doorgeeft als waarde |
| Je gebruikt uit hoofdstuk 2 | `prijs.ts`, de types `number`, `string` en `boolean`, en het lezen van een typefout |
| Wat je oplevert | Een prijs in de opmaak van de klant, een functie `som`, en `korting.ts`: kortingsregels die je kunt combineren |
| Waar je het later gebruikt | Overal. Een React-component is een functie (deel II), een route in Express krijgt een functie (deel III) |

In JavaScript is een functie een waarde: je kunt ze in een variabele stoppen, meegeven
aan een andere functie, of laten teruggeven door een functie. Je deed dat al, met
`addEventListener("click", () => { … })`. Dit hoofdstuk leert je zulke functies te
beschrijven met types. Dat is het stuk TypeScript dat je het vaakst schrijft.
